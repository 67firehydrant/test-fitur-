## 🏠 Selamat Datang di Swaraloka

**Swaraloka** adalah dunia fantasi bernuansa Nusantara — dunia yang lahir dari nyanyian dewa-dewi, dihuni oleh bangsa-bangsa yang memegang kekuatan mantra dan warisan leluhur, dan terancam oleh keheningan yang perlahan menelan segalanya.

## 🎯 Cara Pakai (Pengganti Notion)

### 📖 Menambah Halaman Baru
Buat file `.md` di folder yang sesuai. Contoh:
```
world/characters/raden-wibawa.md
```

### 🗃️ Menambah "Database Entry" (seperti Notion Database)
Gunakan **GitHub Issues** dengan label yang sesuai:
- `character` — untuk karakter baru
- `location` — untuk lokasi baru
- `faction` — untuk faksi baru
- `species` — untuk spesies baru
- `event` — untuk peristiwa sejarah
- `artifact` — untuk artefak
- `lore` — untuk lore umum

### 🔗 Menghubungkan Antar Halaman
Gunakan link markdown:
```markdown
Lihat juga: [[Raden Wibawa]](characters/raden-wibawa.md)
```

### 🖼️ Menambah Gambar
Simpan gambar di folder `world/maps/` atau `world/assets/`, lalu referensikan:
```markdown
![Nama Gambar](maps/gunung-merapi.jpg)
```

### 📋 Template
Gunakan Issue Template yang sudah disediakan — klik **Issues → New Issue** di GitHub.

Proyek ini menggunakan **GitHub sebagai alat worldbuilding** — pengganti gratis untuk Notion. Semua konten disimpan dalam format Markdown yang bisa diakses kapan saja, memiliki version history otomatis, dan bisa dilihat langsung di GitHub.
